# Tide Web — UI kit

A single‑page rebuild of the **tide.co** marketing homepage, using the same
copy ladder, layout shape, and brand vocabulary observed on the live site.

## Run

Open `index.html`. No build step.

## Sections (in order)

| Section | Component |
|---------|-----------|
| Sticky header w/ logo + nav + log‑in + open‑an‑account | `WebNav` |
| Hero — "One account for all things business" + phone mockup | `WebHero` / `WebPhoneMockup` |
| Free MTD‑ready tools strip | `WebMTDStrip` |
| 6‑up feature grid | `WebFeatures` |
| Deep‑navy member quote with Swell motif | `WebQuote` |
| Stay‑in‑the‑loop newsletter card | `WebNewsletter` |
| Footer — Do What You Love lockup + 4 link columns + legal | `WebFooter` |

## Caveats

- Marketing copy is paraphrased from the live site; product names and
  legal text are verbatim.
- The Tide hero usually has a video of real members; we use a stylised
  phone mockup with the deep‑navy balance card instead. Swap in the
  user's video / photo when available.
- The illustrations are abstract — Tide's photography library wasn't
  provided.
