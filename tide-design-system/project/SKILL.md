Read the `README.md` file within this skill, and explore the other available files.

If creating visual artifacts (slides, mocks, throwaway prototypes, etc), copy
assets out and create static HTML files for the user to view. If working on
production code, you can copy assets and read the rules here to become an
expert in designing with this brand.

If the user invokes this skill without any other guidance, ask them what they
want to build or design, ask some questions (mobile or web? marketing or
in‑product? do we have real photography to drop in, or should we use
illustration placeholders? what's the one CTA?), and act as an expert
designer who outputs HTML artifacts _or_ production code, depending on the
need.

Quick start:

- Always use the lavender canvas `#F0F2F8` behind cards, never pure white.
- The hero balance card is **deep navy `#00224F`** with the trademarked
  **Swell** chevron motif — only use it for the primary account surface.
- Buttons are **pills**, weight 700; primary is solid `#2B59FF`, secondary
  is white with a 1px blue border.
- Form fields are **white, 14px radius, no border** — the contrast against
  the lavender canvas is the border.
- Headlines and numerals are extra‑heavy (800).
- Voice: plain, warm, founder‑to‑founder. Sentence case everywhere.
  Always "you/your" for the customer, "we" for Tide. No emoji in core
  flows.
